# Questboard

The Active Quest Board card, served by GitHub Pages from `index.html`.

Its data comes from the Quest Engine (Cloudflare Worker, `rdecaste/quest-engine`) at `GET /questboard`, rebuilt by the 03:00 journal chain. `data.json` here is the last file Make published (27 Sep 2026) and is no longer updated; `backup/` is older history. How it works: Notion page "⚙️ Quest Engine (Cloudflare Worker)" under Quest log.
